## 有效风险

- DSH 客户端桥接仍使用隔离的上游 Loader/service adapter；上游契约变化会禁用不支持能力并需要显式适配，不再使用 DOM 文本猜测。
- 当前桌面构建只允许激活自身冻结图覆盖的 DSH 版本；升级到其他版本必须先生成新的 manifest、lock 和桌面构建。
- macOS arm64 个人包必须在当前 Apple Silicon Mac 完成 DMG/ZIP 安装启动验收；Windows x64 个人包必须由原生 Windows runner 生成并完成 NSIS/ZIP 验收，不能用“等待 CI”关闭 I004。
