## 首次原生冒烟发现与修复

- 初始冻结提交 `c026954fbae73a537a62e4a439716820a8e9d6ac` 成功生成未签名 DMG/ZIP，但 unpacked 应用在 180 秒内没有启动 loopback 服务，因此该提交和制品已判定无效，不得交付。
- 隔离 Profile 的 `plugin-seed.log` 显示 DSH loader 因缺少 `@deepseek-ai/dsh-compaction`、`@deepseek-ai/dsh-atomic-write` 等非可选 peer 提前退出；运行时状态保持 `available`，没有切换为 `current`，证明候选健康失败保护生效。
- 根因是 `npm ci --legacy-peer-deps` 会按设计跳过 peer，而旧冻结清单只显式列出四个启动 peer。修复后把 15 个 DSH peer 与 React/ReactDOM 运行 peer 全部写入单一依赖生成函数和冻结 lock。
- `validateRuntimeCandidate` 现会遍历所有安装包 manifest，按 Node 查找规则验证每个非可选 peer 可解析；新增缺 peer 静态拒绝测试。修复后完整闭包 454 个 npm 包，静态 peer 缺失数为 0。
- 初始无效 DMG/ZIP 只留在 Git 忽略的 `release/` 构建目录，后续重新打包会覆盖；它们不会复制到 `release/personal/`。
